**Twin Hunt** — a spot-the-difference game. Two near-identical pictures side by side, seven sneaky differences hiding in each scene, a clock ticking down, and a detective's eye for detail. Three original hand-drawn scenes (Sunrise Harbour, The Cat Café, Firefly Garden), 21 differences in all, with combos, hints, a time bonus, stars per level, and synthesized sound effects — no assets, no network, just open and play.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Click a difference in either picture to mark it. Wrong clicks cost 5 seconds; `H` spends a hint, `R` restarts the level, `M` mutes the sound.
